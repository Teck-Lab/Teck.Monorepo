# specs/ — OpenAPI Specifications

Auto-generated by Teck.Cloud services. Consumed by `@teck/api-client` for TypeScript type generation.

## Files

One spec per service, versioned:
```
specs/{service}-v1-public.json    ← public-facing API
```

## Codegen

TypeScript types are generated by `src/packages/api-client/scripts/generate.ts`:
```bash
bun run generate    # reads specs/ → writes src/packages/api-client/src/generated/
```

## Rules

- **Never hand-edit specs** — they're auto-generated from .NET API endpoints
- **Never commit generated TS types manually** — run `bun run generate` instead
- **Schema compatibility**: `nx validate-specs` runs before codegen to check backward compatibility
