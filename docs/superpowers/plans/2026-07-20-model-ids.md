## Corrections to the spec's assumptions

1. **The author's model IDs ARE available here.** The spec warned that
   `gpt-5.6-terra` / `sol` / `luna` / `gpt-5.3-codex-spark` were specific to the upstream
   author's account and "must not be copied blind". That was wrong — all four resolve on
   this account. The one ID in his preset that does **not** exist is `gpt-5.6-fast`; the
   fast tier is now expressed as suffixed variants (`gpt-5.6-terra-fast`, etc.).

2. **`auth.json` already existed.** The spec claimed there was no OpenCode credential in
   the container. There was; an earlier probe misreported it. No `opencode auth login` was
   needed for this task.
